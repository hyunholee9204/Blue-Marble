# Blue Marble

갈림길이 있는 웹 보드게임입니다. 부루마블처럼 주사위를 굴려 땅을 사고 통행료를 받으며, 한 화면에서 1~4명이 번갈아 플레이합니다. 봇을 섞어 혼자서도 할 수 있습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

Node.js 20 이상이 필요합니다.

## 맵

| 맵 | 특징 | 특수 단계 |
|---|---|---|
| 한빛 메트로 | 순환선과 두 지선 | Z-DAY: 감염 구역이 번짐 |
| 세계 여행 | 대륙 바깥 해안을 도는 세계 일주 + 지중해·실크로드 | 성수기 |
| 대항해 | 두 섬과 2차선 대교 | 대폭풍 |
| 우주 개척 | 토성형 고리와 행성 | 블랙홀 |
| 놀이공원 | 산책로와 360° 롤러코스터 | 공포의 밤 |
| 화산섬 | 해안 순환로와 나선 등산로 | 대분화: 용암이 흘러내림 |

특수 단계는 맵의 이벤트 칸에 누군가 멈추면 시작되고, 아무도 멈추지 않으면 게임 중반에 자동으로 시작됩니다.

## 규칙 요약

- 출발점을 지나면 월급을 받고, 딱 맞게 멈추면 2배를 받습니다.
- 갈림길에 정확히 멈춘 사람만 다음 차례에 방향을 고릅니다.
- 남의 땅에서는 통행료를 내거나 뺏기에 도전합니다. 더블이 나오면 빼앗고, 실패하면 통행료의 2배를 냅니다.
- 찬스 칸에서는 뒤집힌 카드 10장 중 1장을 고릅니다.
- 순위는 게임 중 공개되지 않고, 끝나면 총자산(현금 + 땅 + 개발비)으로 정합니다.
- 선택 규칙: 게임 길이(20/30/40라운드), 더블 한 번 더, 프리미엄 땅, 밟기

## 구조

```
src/
  engine/      게임 규칙 (순수 reducer, 시드 기반 난수)
  maps/        맵 데이터: 칸, 노선, 단계, 찬스 카드
  game/        React 훅: 이동 애니메이션, 봇
  components/  화면
```

맵은 데이터만으로 정의되므로, `src/maps/`에 파일을 추가하고 `src/maps/index.ts`에 등록하면 새 맵이 생깁니다.

## 기술

React 19, TypeScript, Vite
